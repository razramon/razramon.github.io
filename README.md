# razramon.github.io

My blog, built by GitHub Pages with Jekyll and the minima theme.

- New post: add `_posts/YYYY-MM-DD-title.md` with a front-matter block (`layout: post`, `title`, `date`), commit, push.
- Images go in `assets/img/` and are linked as `/assets/img/...`.
- Preview locally (optional): `bundle install`, then `bundle exec jekyll serve` and open http://localhost:4000.
